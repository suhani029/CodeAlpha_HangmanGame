# Hangman Game – Python

## Project Overview
This project is a simple text-based Hangman Game developed using Python as part of my CodeAlpha Python Programming Internship.

The computer randomly selects a word from a predefined list of five words, and the player has to guess it one letter at a time.

## Features
- Random word selection.
- Five predefined words.
- Maximum six incorrect guesses.
- Displays correctly guessed letters.
- Checks repeated guesses.
- Validates user input.
- Displays winning and losing messages.

## Technologies Used
- Python 3
- Random module
- VS Code

## Concepts Used
- Variables and data types
- Lists and strings
- Random module
- While and for loops
- If-else conditions
- User input and output

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python hangman.py
```
